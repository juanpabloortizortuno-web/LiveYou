# LiveYou

Página web para transmitir, chatear y compartir experiencias: videos cortos, en vivo y chat.

## Archivos
- `index.html` – la aplicación completa
- `manifest.webmanifest`, `favicon.ico`, `icons/` – íconos e instalación como app
- `supabase-setup.sql` – base de datos (se pega a mano en Supabase → SQL Editor)

## Publicar
GitHub → Settings → Pages → Branch `main` / carpeta `/ (root)`.
